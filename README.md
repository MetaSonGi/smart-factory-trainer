# 스마트 공장 검증 장비 — 실습 시뮬레이터

스마트공장 교육용 **검증 장비 실습 시뮬레이터** 웹앱입니다.
3D 가상 장비로 설비 기동 → 컨베이어 가동 → 로봇팔 이송 → 비전 검사 → 불량 분류까지
전 공정을 직접 조작하며 배우는 차시형 실습 콘텐츠입니다.

🌐 **바로 실행:** https://metasongi.github.io/smart-factory-trainer/

## 구성

- **과정 랜딩**: 과정 카드 (스마트 공장 / 스마트 공장 검증 장비 / 1차시 · 약 2시간)
- **3D 실습 장면** (Three.js)
  - 컨베이어 라인 + 제품 투입
  - 로봇팔 픽앤플레이스
  - 비전 검사 스테이션 (양품/불량 램프)
  - 양품/불량 분류 박스
  - 제어 패널 (전원·가동 램프)
- **실습 단계 엔진**: 5단계 가이드 (전원 → 컨베이어 → 로봇팔 → 비전검사 → 분류 확인)
- **실시간 대시보드**: 생산량·양품·불량·불량률 + 검사 추이 그래프
- **이해도 평가**: 5문제 퀴즈, 4문제 이상 시 수료 판정

## 실행 방법

정적 웹앱이라 서버가 필요 없습니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 기술 스택

- Three.js (CDN) — 3D 장비·공정 시각화
- Vanilla JS — 실습 시나리오 엔진, 대시보드, 퀴즈
- 모든 처리는 브라우저에서 수행
